We built FlowInOne to tackle a core challenge in multimodal generative modeling: how to unify wildly different input modalities—like a rough sketch, a scribbled note, a box-and-arrow diagram, or a symbolic command—into a single, coherent visual prompt that can guide image generation. Traditional approaches often rely on modality-specific encoders and complex fusion mechanisms, or they require separate models for each input type. This modularity limits flexibility and makes it hard to compose inputs naturally, like drawing a sketch and jotting a note in the corner. Our motivation was to shift from *processing* modalities separately to *representing* them all as visual signals in a shared space—treating everything as “image-like” data that a single generative model can understand. By doing so, we aim to mimic how humans intuitively combine visual cues: not by parsing text or diagrams symbolically, but by perceiving them as part of a unified visual scene.

At the core of FlowInOne is a visual representation learning framework that maps all inputs into a denoisable 2D latent canvas. Each modality—sketch, text, layout, or symbol—is first preprocessed into a rasterized image format (e.g., grayscale or multi-channel maps), preserving spatial structure. These are then encoded via a shared convolutional or vision-transformer backbone into a common latent space, where they’re fused using cross-attention or simple concatenation with positional priors. The key innovation is that this fused visual latent is not just a static embedding; it’s a structured, spatially aligned representation that serves as the initial condition for a flow matching generative model. Flow matching, unlike diffusion, directly learns to transport latent noise to data by predicting trajectories, enabling faster, more stable generation. Our model is trained to generate photorealistic images by treating the fused visual prompt as the sole conditioning signal—no separate text encoders, no modality-specific heads. At inference, users can literally “draw” their prompt: sketch a tree, write “sunset” in cursive, add a bounding box labeled “dog,” and the model generates a coherent image as if interpreting a rough design sketch.

What we learned is that visual unification works surprisingly well—but only when spatial semantics are preserved. Early versions that flattened inputs into vectors failed to generate spatially accurate outputs, confirming that geometry matters as much as content. We also found that the model learns implicit modality disambiguation: it can distinguish handwritten text from doodles based on stroke patterns and context, even without explicit labels. However, limitations remain. Fine-grained symbolic instructions (e.g., “make the car red and shiny”) are often underinterpreted, suggesting that dense visual encoding has a bandwidth ceiling compared to language. Additionally, the reliance on rasterization limits resolution and scalability. Future work could explore hybrid vector-raster representations or adaptive tokenization to handle complex symbols more efficiently. We’re also excited by the potential to invert the process—using the same flow to go from image back to editable visual prompt, enabling round-trip design.

FlowInOne sits at the intersection of several trends: the move toward unified architectures (like Flamingo or PaLI), the rise of flow-based generation for efficiency, and the growing interest in visual prompting as a UI paradigm. It challenges the dominance of text-conditional models by asking: what if the prompt doesn’t have to be language at all? In doing so, it aligns with work on sketch-based interfaces and embodied AI, where communication is inherently multimodal and spatial. By treating generation as a visual-to-visual translation task, FlowInOne offers a step toward more intuitive, accessible, and human-aligned creative tools.
