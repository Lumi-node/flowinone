# Installation

## From PyPI

```bash
pip install flowinone
```

## From Source

```bash
git clone https://github.com/Lumi-node/flowinone.git
cd flowinone
pip install -e ".[dev]"
```

## Requirements

- Python >= 3.10
- Dependencies: , "all, %(module)s, Cython, OpenSSL, PIL, PyInstaller, __future__
